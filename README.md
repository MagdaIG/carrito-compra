# carrito compra

Shopping cart web app built with JavaScript, featuring dynamic DOM manipulation and price totals.

## Tech Stack

HTML5, CSS3, JavaScript and Bootstrap

## Getting Started

```bash
git clone https://github.com/MagdaIG/carrito-compra.git
cd carrito-compra
Open index.html in your browser
```
